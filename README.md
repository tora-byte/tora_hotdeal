# ToraHotDeal

ToraHotDeal is a mobile-first hot deal community MVP built with Next.js 15, TypeScript, Tailwind CSS, and Supabase.

## Environment

Create `.env.local` for local Supabase integration:

```bash
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

## Scripts

```bash
npm run dev
npm run lint
npm run build
```
